¿Qué es una skill?

Una skill es una colección de instrucciones y recursos reutilizables. Por ejemplo, puede enseñar a un agente a revisar accesibilidad, diseñar interfaces o crear pruebas. En varias herramientas se describe mediante un archivo llamado SKILL.md .

Skills, subagentes y MCP

Son conceptos relacionados, pero diferentes: una skill indica cómo realizar una tarea; un subagente puede encargarse de una tarea delimitada y trabajar con su propio contexto; un servidor MCP ofrece acceso controlado a herramientas externas.

Idea para un hackathon: asignar un agente a frontend, otro a backend y otro a pruebas. Cada uno aporta resultados, pero una persona debe revisar e integrar los cambios.
