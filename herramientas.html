El ecosistema vibe coding.

Claude Code, gstack, Stitch, MCP y otras herramientas que hacen posible trabajar con agentes especializados.

Inicio / Herramientas

Herramientas para cada etapa

CC

Claude Code

Agente de programación que puede explorar archivos, modificar código, ejecutar tareas y seguir instrucciones especializadas.

Documentación ↗
GC

Gemini CLI

Herramienta de programación de Google que trabaja desde la terminal y admite extensiones e integraciones.

Documentación ↗
ST

Google Stitch

Ayuda a generar pantallas e interfaces a partir de descripciones para acelerar la fase visual.

Documentación ↗
AG

Agentation

Permite realizar anotaciones sobre una interfaz y entregarlas como observaciones precisas al agente.

Documentación ↗
GS

gstack

Conjunto de procedimientos y skills para organizar planificación, revisión y pruebas del desarrollo.

Documentación ↗
GT

Git Worktrees

Permite abrir distintos directorios de trabajo para desarrollar funciones en ramas separadas.

Documentación ↗
MC

MCP

Protocolo que conecta asistentes de IA con herramientas y servicios externos.

Documentación ↗
PW

Playwright

Automatiza pruebas de navegación, formularios y funciones en aplicaciones web.

Documentación ↗

¿Cómo se conectan?

Un flujo sencillo puede comenzar con Google Stitch para bosquejar una interfaz, continuar con Claude Code o Gemini CLI para implementarla y terminar con pruebas automatizadas mediante Playwright. MCP permite integrar ciertas herramientas con el agente.

Importante: algunas funciones necesitan una cuenta, permisos especiales o planes de pago. Las condiciones pueden cambiar según el servicio.
